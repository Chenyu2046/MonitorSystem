# KernScope Dashboard — V2 UI 设计规范

## 定位与参照
- 产品：Linux 主机性能观测与 AI 故障诊断工作台。
- 视觉参照：用户提供的 Ember 深色侧栏图。借鉴布局、信息层级和克制的配色，不复制其品牌、财务数据、商业图形。
- 设计目标：Neutral Dark。去除全局薄荷绿主题与模板化图标；性能数据、状态色保留语义。

## 核心视觉规则
- 主画布 `#101110`、侧栏 `#121312`、面板 `#191b1a`、分隔线 `#292d2a`。
- 主要文本 `#f0f1ee`、次要文本 `#a0a6a0`。
- 交互控件默认灰白（`#e1e4df`），侧栏选中态为中性灰（`#2c2e2d`），**不使用绿色作为全局品牌强调**。
- 绿色仅代表正常/在线及业务数据序列；黄色用于警告、红色用于异常。CPU/内存/磁盘/网络的趋势曲线保留不同数据颜色。
- 强调靠字号、留白、分区、字重，不依赖渐变、大面积绿底、发光描边、无语义图标。

## 导航与信息密度
- 一级导航（总览、查询）保留功能图标。
- 侧栏下半部分「主机指标」用小圆点代替图标：CPU = amber，内存 = blue，磁盘 = purple，网络 = pink。**仅这些分类点采用轻微光晕**。
- 列表条目约 43px；侧栏桌面宽度 252px，1050px 以下 226px，720px 以下缩为 58px 图标/圆点轨道。
- KPI 用四个简单容器，移除图标角标及单个绿色高亮卡片；标题、数值、注释构成字阶。
- 表格不渲染原始 JSON 字符串，诊断信号采用可展开明细。
- 去除「当前视图调用后端查询接口」等重复的说明性 UI 文案。主标题与局部标题遵守信息层级。

## 功能契约
- 真实数据：性能图表按 timestamp 对齐，不以数组位置凑时间序列；缺失指标不补 0。
- 在线标记：Socket.IO 连接状态与节点有无数据分别表达。
- 操作可用：评分选择、导航、查询筛选、详情刷新、AI 面板。
- AI Agent 只读、只取 KernScope 查询/诊断证据，失败说明，不修改系统配置。

## QA 验收
- 桌面 1440px / 1920px：侧栏圆点、菜单文案左对齐；导航选中无绿色底。
- 720px / 390px：侧栏窄轨道仍能点击目标，不遮挡顶部栏；图表/表格横向可查看。
- 总览：只有业务图表、状态指示可以用绿；KPI 不带重复装饰性图标。
- 切换性能、诊断、评分列表；空态、长主机名和无数据状态保持可读。
- 不增加新的依赖，不改 Worker、Manager、Proto、SQL。

上游 Dashboard 仍遵循 Apache-2.0 许可；改造设计归属于 KernScope 的前端表现。
