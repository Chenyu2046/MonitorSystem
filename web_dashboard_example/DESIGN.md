# KernScope Dashboard — UI 设计锚点

目标：Linux 主机监控与 AI 故障分析工作台。风格依据：用户提供的 Ember 暗色侧栏参考图；保留 KernScope 的功能与数据含义，不照搬 Ember 的财务内容或品牌资产。

## 页面行为与功能契约
- 3 秒内找到当前页面、主机在线状态、资源 / 健康评分和主要性能趋势。
- 侧栏导航在桌面左对齐、同列同宽；当前页面只有一个明确选中态。
- 性能曲线按真实采样时间对齐；缺失值不是 0；网络指标使用 KiB/s → MB/s 转换。
- 查询表中的诊断信号以可读明细展示，避免原始长 JSON 撑宽表格。
- 刷新、筛选、导航、AI 分析保持可访问与可恢复的行为。

## 设计变量
- 画布 `#101110`；侧栏 `#121312`；面板 `#191b1a`；发丝边框 `#292d2a`。
- 主要文字 `#f0f1ee`；次要文字 `#a0a6a0`；强调 `#65c2a0`。
- KPI 大数字 25–35px，tabular nums；中文采用系统字体，不额外加载中文 Webfont。
- 导航宽 252px；条目高约 43px；圆角 9–12px；主内容栏留白 26–34px。
- 深色低对比边框、无装饰性 glow、渐变和玻璃拟态。
- 保留图表黄 / 绿 / 蓝的指标区分；异常色只用于异常。

## 响应式和状态
- 1050px 以下缩小导航至 226px；720px 以下转为 58px 图标轨道。
- 侧栏独立纵向滚动且禁止横向溢出，滚动条变窄。
- 使用 `socketConnected` 而非“已有数据”判定实时连接状态。
- 图表与表格保留空态、无数据态；诊断信号支持局部展开。
- 只对 hover/selected 使用短时颜色过渡；遵守 prefers-reduced-motion。

## 避免
- 不为风格而新增卡片、图形、假数据或外部依赖。
- 不引入新的构建系统。
- 不修改 C++ 后端和 gRPC 协议。
